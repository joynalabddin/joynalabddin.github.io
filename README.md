## Frequently Asked Questions

### Can you guarantee that a hacked site will never be attacked again?

No. Cleanup, updates, access control, backups, monitoring, and maintenance reduce risk, but no honest professional can promise permanent immunity.

### Can you guarantee that Google rankings will be restored after migration or cleanup?

No. Technical cleanup and careful migration can reduce avoidable problems, but search visibility depends on content, redirects, indexing, links, competition, user needs, technical conditions, and time.

### What should I send for a first enquiry?

Send the public URL, a short description of the problem, approximate scope, preferred timeline, and whether a backup exists. Do not send passwords, API keys, private analytics, or personal data in public channels.

### Do you work with agencies and resellers?

Agency support and white-label technical delivery can be discussed when the scope, client ownership, communication, payment, confidentiality, and handover responsibilities are clear.
