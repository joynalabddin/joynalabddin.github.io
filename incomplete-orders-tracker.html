How it works

From checkout field to recovery action.

1. Customer starts checkout

A private session identifier connects the browser journey without putting personal data inside the identifier.

2. Context is saved

Sanitized checkout fields and product details are saved to the store's own WordPress database.

3. Order is matched

When the customer completes payment, the newest eligible incomplete record is marked complete.

4. Admin follows up

Use WhatsApp, email, phone, map, product link or CSV export from the dashboard.

Free means free. This plugin does not require a license key, activation key, paid plan or remote license server. WordPress's normal plugin activation is used only to create or repair the local table and schedule maintenance.
Frequently asked questions

Common questions about the free WooCommerce plugin.

Is Incomplete Orders Tracker free?

Yes. It is free to use and does not require a license key, paid activation, account connection or remote licensing service.

Does it support WooCommerce Block Checkout?

Yes. It supports Classic Checkout and WooCommerce Block Checkout, with session-first order matching and recent email or phone fallback matching.

How do updates work?

New versioned GitHub Releases provide update metadata and a ZIP file. WordPress shows an update notification and the administrator approves the update.

Is customer data sent to GitHub?

No. Checkout data is stored in the store's own WordPress database. GitHub is used only for public version metadata and release downloads.
